# ADR 0004 — GUIDU como nome provisório

- **Status:** Aceito
- **Data:** 07/10/2026
- **Aprovador:** Marcelo
- **Decisão de origem:** D4, documento `decisoes` da [SMA-88](https://paperclip.local/SMA/issues/SMA-88)

## Contexto

O projeto precisa de uma identidade operacional enquanto nome e marca ainda podem mudar.

## Decisão

O nome provisório é **GUIDU** e o domínio futuro é **console.guidu.co**. Ambos são valores configuráveis por ambiente e nunca ficam fixos no código.

## Consequências

Textos, URLs e integrações devem ler configuração, permitindo troca posterior sem alteração espalhada pelo produto.
